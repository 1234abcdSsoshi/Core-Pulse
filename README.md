P1「Azure Wing」とP2「Solar Fang」が協力してコアを守りながら敵を撃破します。

## 操作方法

### タイトル画面

| キー | 操作 |
|------|------|
| `1` | Story Mode |
| `2` | Astral Court |
| `3` | Eclipse Leviathan Raid |
| マウスクリック | 各ボタンで選択 |

### ゲームプレイ中（共通）

| キー | 操作 |
|------|------|
| `ESC` | ポーズ / 再開 |
| `Tab` | ショップを開く / 閉じる（Story Mode のみ） |
| `R`（ゲームオーバー時） | リトライ |

### P1（Azure Wing）

| キー | 操作 |
|------|------|
| `W` `A` `S` `D` | 移動 |
| `F` | ショット |

### P2（Solar Fang）

| キー | 操作 |
|------|------|
| `↑` `←` `↓` `→` | 移動 |
| `L` | ショット |

### フュージョン発動（Story Modeのみ）

| キー | 操作 |
|------|------|
| `G` / `K` / `Space` | CO-OP LINK 100%時にフュージョン発動 |

### フュージョン中の操作

| キー | 操作 |
|------|------|
| `W` `A` `S` `D`（P1） | 照準ポインターを移動 |
| `F`（P1） | フュージョンキャノン発射 |
| `↑` `←` `↓` `→`（P2） | フュージョン艦体を移動 |
| `L`（P2） | 爆弾を設置 |

## ゲームモード

### Story Mode（ストーリーモード）

- P1・P2 がコアを守りながら敵の波を乗り越えるCO-OPモード
- 敵を一定数倒すごとにウェーブクリアとなりアップグレードを選択できる
- コアのHPが0になるとゲームオーバー
- 敵を倒すと **クリスタル** が出現し、集めると **ショップ** で強化アイテムを購入できる

### Astral Court（アストラルコート）

- P1 vs P2 の1対1対戦モード
- 相手のHPを先にゼロにした方が勝ち

### Eclipse Leviathan Raid（レイドモード）

- 2人で巨大ボスに挑むレイドモード
- ボスはフェーズごとに強化・移動パターンが変化する

## キャラクター性能

### P1：Azure Wing（アジュールウィング）

- **移動速度**：速い
- **弾速**：高い
- **射撃間隔**：短い（連射向き）
- **弾のサイズ**：小さい精密弾
- **1発あたりダメージ**：低め

**アイテム効果（P1専用）**
- Rapid Fire：超高速連射
- Power Boost：貫通レーザー

### P2：Solar Fang（ソーラーファング）

- **移動速度**：遅い
- **弾速**：低い
- **射撃間隔**：長い（重火力向き）
- **弾のサイズ**：大きい重弾
- **1発あたりダメージ**：高い

**アイテム効果（P2専用）**
- Rapid Fire：3連バースト射撃
- Power Boost：巨大重弾

## フィールドアイテム一覧

フィールドに自動スポーンするアイテムです。機体が触れると即時効果が発動します。

| アイテム | 効果 |
|---------|------|
| Heal | コアHP +20 回復 |
| Rapid Fire | 一定時間、射撃速度が上昇 |
| Shield | コアをダメージから保護（時間制） |
| Power Boost | 一定時間、強化弾を発射 |
| Link Charge | CO-OPリンクゲージを大幅補充 |

> Link Chargeの出現率は他アイテムより低めに調整されています。

## クリスタルシステム

### 入手方法

敵を撃破すると **青い菱形のクリスタル** がその場に出現します。
敵の強さによってドロップ数が異なります。

| 敵の種類 | ドロップ数 |
|---------|----------|
| Scout（小型スカウト） | 1個 |
| Attacker（通常攻撃機） | 2〜3個 |
| Tank（重装甲） | 5〜7個 |
| Elite（精鋭機） | 7〜10個 |

### 回収方法

- クリスタルに **機体を近づける**（半径120px以内）と自動で吸い寄せられ回収されます
- 回収されなかったクリスタルは約5秒後に消滅します
- 画面右上の **💎 XX** が所持数を示します

> ショップで **Crystal Magnet** を購入すると吸引範囲が3倍（360px）に広がります。

## ショップ

クリスタルを使って機体・コアを強化できます。

### 開き方

- **`Tab` キー**を押す
- または画面右上の **「SHOP」ボタン** をクリック

ショップを開くとゲームとBGMが一時停止します。`Tab` または `ESC` で閉じると再開します。

> 購入可能なアイテムがある場合、SHOPボタンが **緑色に光って** お知らせします。

---

### アイテム（消耗品）

購入すると即時効果が発動する消耗品です。

| アイテム名 | 価格 | 効果 |
|-----------|------|------|
| CORE REPAIR | 💎 20 | コアのHP を +40 回復する |
| MEGA BOMB | 💎 35 | 画面上の全敵を即座に撃破する |
| CRYSTAL MAGNET | 💎 15 | 60秒間、クリスタルの吸引範囲が3倍になる |
| OVERCLOCK | 💎 30 | 30秒間、P1・P2の射撃速度が1.5倍になる |
| EMP BURST | 💎 25 | 5秒間、全敵の動きと攻撃を停止させる |

### 武器（機体に装備）

P1またはP2の機体に取り付ける追加武器です。
購入時に **「P1 Azure Wing」か「P2 Solar Fang」かを選ぶ** UIが表示されます。

- 1つの機体に装備できる武器は1種類のみ（後から別の武器を買うと上書き）
- 装備した武器は通常ショットと同時に自動で発射されます

| 武器名 | 価格 | 効果 |
|--------|------|------|
| SIDE CANNON | 💎 25 | 通常弾に加え、左右2方向へ追加弾を発射する |
| SPREAD SHOT | 💎 30 | 通常弾に加え、左右25°に広がる追加弾を2発発射する |
| HOMING MISSILE | 💎 45 | 2.5秒ごとに最寄りの敵へ自動追尾ミサイルを発射する |
| TWIN LASER | 💎 60 | 通常弾に加え、左右に平行した2本の追加レーザーを発射する |

#### 武器の購入手順

1. ショップを開く（`Tab` キーまたはSHOPボタン）
2. WEAPONS欄から欲しい武器の **「BUY」** をクリック
3. **「P1 Azure Wing」または「P2 Solar Fang」** を選択
4. クリスタルが引き落とされ、即座に装備される

---

### 設置型タレット（コア周囲に自動配置）

コアの周囲に設置される自動攻撃砲台です。
最大 **3基** まで設置でき、設置するたびにコアを囲むよう120°間隔で自動配置されます。
タレットは購入後に特定のキー操作は不要で、自動で敵を攻撃し続けます。

| タレット名 | 価格 | 効果 |
|-----------|------|------|
| AUTO CANNON | 💎 40 | 1.2秒ごとに最寄りの敵へ弾を発射する |
| LASER TOWER | 💎 55 | 0.08秒ごとに最寄りの敵に連続ダメージを与えるレーザーを照射する |
| MISSILE POD | 💎 70 | 3.5秒ごとに近い敵3体に同時追尾ミサイルを発射する |
| SHIELD WALL | 💎 35 | コアに近づいた敵を8秒に1回弾き返す防壁を展開する |

#### タレットの購入手順

1. ショップを開く
2. TURRETS欄から欲しいタレットの **「BUY」** をクリック
3. クリスタルが引き落とされ、コア周囲に自動配置される

> 3基すでに設置されている場合は購入できません。

## フュージョンモード

Story Mode専用の強力な合体システムです。

### 発動条件

- P1・P2が互いに近い位置、またはコア付近にいると **CO-OP LINKゲージ** が蓄積する
- ゲージが100%になったら `G` / `K` / `Space` を押して発動
- Link Chargeアイテムで即時大量補充可能

### フュージョン中の性能

| 項目 | 内容 |
|------|------|
| 持続時間 | 12秒 |
| フュージョンキャノン | ポインター方向へ高威力射撃（P1: F） |
| 爆弾 | 最大3個、半径185pxの範囲攻撃（P2: L） |
| 耐久 | 通常敵は爆弾1発で即死、タンク敵は重ダメージ |

### 演出

- 発動時に**青白いフラッシュ**が点灯
- 画面上部に**フュージョン残り時間バー**（緑色）が表示され、時間経過で縮小
- 終了時「FUSION COMPLETE」と表示され通常モードに戻る

## オンラインプレイ

ブラウザ経由で2人がオンラインで対戦・協力できます。

### プレイ方法

1. タイトル画面の **ONLINE LOBBY** をクリック
2. プレイヤー名を入力して **CONNECT**
3. ホスト側が **CREATE ROOM** → ルームコードが発行される
4. ゲスト側がルームコードを入力して参加
5. P1 / P2 の役割を選択して **READY**
6. 両プレイヤーがReadyになると **START GAME** でゲーム開始

### ゲームURL

`https://1234abcdssoshi.github.io/twin-core-blasters-1.0/`

## サーバーの起動方法

ローカルでサーバーを動かす場合の手順です。

```powershell
cd server
npm install
npm start
```

起動成功時のメッセージ：

```
Twin Core Blasters WebSocket server listening on ws://0.0.0.0:8080
```

> 本番サーバーは Render.com に常時稼働中です。ローカル起動は開発・デバッグ用途です。

## 追加・変更した機能

| 機能 | 内容 |
|------|------|
| クリスタルシステム | 敵撃破時にクリスタルをドロップ。敵の強さで数が変わる |
| ショップ | TabキーまたはHUDボタンで開閉。クリスタルで武器・タレット・アイテムを購入 |
| 武器（4種） | Side Cannon / Spread Shot / Homing Missile / Twin Laser。P1/P2に個別装備 |
| 設置型タレット（4種） | Auto Cannon / Laser Tower / Missile Pod / Shield Wall。コア周囲に最大3基 |
| ショップ通知 | 購入可能なアイテムがあるとSHOPボタンが緑色に光る |
| ポーズメニュー | ESCキーでゲームを一時停止。Resume / Home ボタンを表示 |
| BGM一時停止 | ポーズ中・ショップ表示中は曲が止まる |
| 弾の向き修正 | P1・P2の弾スプライトが進行方向に正しく向くよう修正 |
| フュージョン演出強化 | 発動時に青白いフラッシュ・残り時間バーを追加 |
| Link Charge調整 | 出現率を他アイテムより低く調整 |
| コア体力の設定変数化 | `Main.gd` 冒頭の `CORE_HP_MAX` を変更するだけで体力を調整可能 |
| ショップアイコン刷新 | 武器4種・タレット4種・アイテム2種・HUDアイコンを高品質画像に再生成（`generate_assets.py`） |
